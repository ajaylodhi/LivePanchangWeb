## 📌 Overview

This directory contains the lightweight, high-performance, single-page scrolling website for **Live Panchang**. It is designed using modern web standards, standalone CSS (`style.css`), and embedded vanilla JavaScript with zero external heavy frameworks or dependencies.

The web portal serves as a marketing showcase, feature walkthrough, and privacy policy landing page for users and Jyotish practitioners interested in the Live Panchang Android mobile app.
